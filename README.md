# نظام تحليل واقع المدرسة

منظومة ويب تفاعلية مخصصة لتحليل وتشخيص الواقع المدرسي، ومتابعة الأداء، البرامج، والتقويم الذاتي.

## المميزات
- **لوحة تحكم تفاعلية (Dashboard):** عرض مؤشرات أداء غياب الطلاب والمعلمين ونسب الفجوة.
- **ربط مباشر مع Google Sheets:** يعمل الشيت كـ Backend مجاني وسريع وسحابي.
- **إدخال وتحديث حي:** إرسال البيانات من المتصفح مباشرة للجدول بدون الحاجة لأدوات مدفوعة.
- **طباعة وتصدير:** تصدير السجلات بصيغة Excel/CSV، ودعم الطباعة المباشرة لتوليد التقارير.

## التثبيت والتشغيل
1. ارفع الكود على أي مستودع في **GitHub**.
2. فعّل خدمة **GitHub Pages** من إعدادات المستودع (Settings -> Pages -> Branch: `main`).
